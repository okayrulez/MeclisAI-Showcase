# Meclis AI

An AI application for exploring files through mind maps, adding information through conversation and generating documents from collected knowledge.

I built workflows that help users organize, edit and reuse their source material, alongside a Windows application and AI integrations for document processing.

**Technologies and areas:** C#/.NET, WPF, AI integration, document processing, knowledge organization.

**Website:** https://meclisai.com

This repository introduces the project. Application source code is private.
